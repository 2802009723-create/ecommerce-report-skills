# 库存补货



库存是否可信，哪些商品可能断货，补货决策还缺什么条件？



最低资料：可比库存快照可做核对；补充销售历史、交期和在途后才能形成补货测算。



## 可用模块



### 库存一致性与可售量

问题：不同系统看到的库存是否是同一范围？

方法角色：AG02

输入：库存快照与库存类型定义

维度：SKU、仓库、库存类型

指标：库存差异：同 SKU、同仓、同库存类型、可比时点的数量差；可售库存：根据已确认规则扣除锁定、占用或不可售部分，避免重复扣减

图形意图：库存差异明细、仓库对比

成立条件：先对齐快照时间、箱件单位和仓库映射；未经对齐不报告账实差。

建议：将差异定位到具体 SKU、仓库和来源记录。

验证：在可比时点复核修正记录与剩余差异。



### 覆盖、周转与滞销风险

问题：哪些商品存在供给不足或库存沉积风险？

方法角色：AG02、AG09

输入：库存快照、销售历史；效期判断另需批次资料

维度：SKU、仓库、批次、需求场景

指标：库存覆盖天数：可售库存 ÷ 明确窗口的日均需求；均值为零时转入无动销观察；库龄与效期风险：依据批次日期、效期和业务规则计算，不凭总库存推断

图形意图：覆盖天数与规则线对比、库龄分布

成立条件：促销或季节变化应单独说明；均销不是确定的未来需求。

建议：区分保供、滞销和临期问题，分别安排核查。

验证：复查库存结构与需求变化，避免仅用库存下降判断处理有效。



### 补货与到货跟踪

问题：何时补、补多少，还受哪些条件限制？

方法角色：AG04、AG10

输入：需求条件、采购与在途、交期及供应约束

维度：SKU、供应商、到货批次

指标：库存位置：按口径综合可用库存、有效在途与待履约需求，防止重复计入；补货建议量：依据覆盖目标和需求情景测算缺口，再考虑起订量、包装倍数和约束

图形意图：预计供需时间线、到货计划表

成立条件：在途、交期或需求条件缺失时不输出确定采购量；预测标明假设。

建议：核实供货条件后提交可追踪的补货方案。

验证：到货后复查供给覆盖与实际动销，比较预测和实际差异。



## 口径规则

- 库存类型、仓库、计量单位与快照时间必须先对齐。

- 补货预警线按实际交期和安全要求配置，不设置通用固定天数。

- 均销为零不显示无限覆盖，应转入无动销或低样本判断。

- 采购下单、调拨和库存修改需要业务确认，日报负责提供测算与依据。

# 利润与结算



经营贡献变化在哪里，结算是否匹配，哪些差异尚待确认？



最低资料：成交明细可展示收入构成；完整成本费用才支持贡献利润，结算判断另需账单与流水。



## 可用模块



### 收入与业务贡献

问题：在已确认口径下，经营贡献如何变化？

方法角色：AG06

输入：订单、退款、成本与费用及口径说明

维度：渠道、商品、订单归属期

指标：净收入：依据已确认的收入、退款和税费口径形成同归属期金额；业务口径贡献利润：同口径净收入减纳入该口径的成本费用；明确不等同于完整会计净利润

图形意图：收入到贡献的桥接图、同口径贡献趋势

成立条件：项目完整且无重复扣减才画完整利润桥；有缺项时展示已知部分和缺口。

建议：定位贡献变化最大的收入或成本项目。

验证：补齐费用后复算，保留预估版本与确认版本差异。



### 费用变动与分摊

问题：哪项费用影响贡献，分摊是否可复核？

方法角色：AG06、AG08

输入：成本与费用、收入范围和分摊规则

维度：费用项目、渠道、商品

指标：分项费用与费用率：按同归属期分项列示；比例使用明确且一致的收入分母；分摊结果：按已确认规则分配共享费用，分项合计应回到原始总额

图形意图：费用结构、差异贡献图

成立条件：分摊规则未确定时保留未分摊金额，不制造商品级精确利润。

建议：核实异常费用与重复计入，并提出可复核的处理事项。

验证：复核修正凭据、分摊规则及对业务贡献的实际影响。



### 结算、到账与差异

问题：应结、已结与实际到账是否对应？

方法角色：AG21

输入：平台账单、结算单、资金流水与订单关联

维度：平台、账期、结算单、差异类型

指标：结算状态金额：依平台账单区分待结、已结和账期，不直接等同订单支付金额；到账与差异：按结算单关联流水，区分时间差、扣费差和无法匹配项

图形意图：结算匹配表、差异账龄分布

成立条件：先确认账期与应到日期；账期未到不直接列作异常欠款。

建议：逐项定位差异来源，分配核对与补证责任。

验证：以可关联的账单、流水或修正记录确认差异关闭。



## 口径规则

- 业务贡献、会计利润和现金到账分开命名，避免混为一个经营指标。

- 收入、退款、成本和费用统一归属期；税费及分摊口径由业务和财务确认。

- 缺失成本费用不能补零，预估数与确认数应分开标记。

- 结算差异先核对账期和时间差，再判断是否需要处理。

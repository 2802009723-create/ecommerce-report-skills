# 经营总览



整体进展如何，主要差距在哪里，今天优先协调什么？



最低资料：同口径的成交汇总可以形成经营结果模块；没有目标或专项资料时，不输出对应达成率和专项风险判断。



## 可用模块



### 经营结果与目标进度

问题：当前结果距离计划还有多远？

方法角色：AG03、AG08

输入：成交汇总；目标计划仅用于进度判断

维度：渠道、店铺、日期

指标：支付金额 / 同口径净成交：按已确认的订单状态和退款口径分别计算，不能混用；目标达成率：同周期累计实际 ÷ 对应累计目标；目标缺失或为零时不计算

图形意图：实际与目标对比图、同口径趋势图

成立条件：实际与目标的范围和累计时点一致；缺目标时保留实际趋势。

建议：把经营差距拆到业务负责人能够处理的对象。

验证：在相同范围和周期口径下复查差距变化，区分已执行与已改善。



### 增长与下滑来源

问题：哪些渠道或业务单元拉动了整体变化？

方法角色：AG03

输入：带渠道或业务单元维度的成交汇总

维度：渠道、店铺、商品组

指标：分项金额变化：各分项当期值减可比基期值；分项变化应与总体变化相符；结构占比：分项值 ÷ 同范围总值；零总值时不计算

图形意图：变化贡献条形图、渠道结构图

成立条件：分项需可相加；分项中包含负值时不使用普通占比饼图。

建议：优先跟进对整体变化贡献最大的可处理问题。

验证：复查同一业务单元的变化，保留基准与异常事件说明。



### 跨模块风险与协调

问题：哪些问题需要经营负责人协调资源？

方法角色：AG08、AG05

输入：专项结果、原始依据与未结事项

维度：影响范围、紧急程度、责任岗位

指标：未解决事项：去重后的问题记录，保留来源、影响范围和当前状态；专项风险指标：引用已复核的库存、费用或售后模块；资料未提供时不填零

图形意图：风险清单、事项状态分布

成立条件：问题优先级采用事先约定的影响和时效标准，不将缺数据判为无风险。

建议：形成有责任岗位、期限和验证要求的协调事项。

验证：既检查事项是否完成，也检查对应业务影响是否解除。



## 口径规则

- 目标与实际需匹配相同周期；累计目标未拆分时，不把全周期目标直接用于单日判断。

- 支付、退款和净成交分开命名；说明退款按发生日还是订单归属期统计。

- 跨渠道的访客与买家可能重复，未经跨渠道去重不得标为独立用户总数。

- 首页优先级依据经营影响与可行动性，避免将各专项日报原文全部拼接。

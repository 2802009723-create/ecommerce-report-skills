# 广告投放



预算花在哪里，带来什么可归因结果，下一步验证什么？



最低资料：消耗明细可形成预算模块；有一致归因口径的转化回传后才计算效率指标。



## 可用模块



### 消耗与预算节奏

问题：消耗是否偏离已约定的投放计划？

方法角色：AG14、AG08

输入：消耗与预算

维度：渠道、计划、日期

指标：广告消耗：按平台、计划和日期去重汇总；预算执行与剩余：预算与消耗匹配同一周期；剩余 = 预算 − 累计消耗

图形意图：累计消耗与预算对照、计划消耗排行

成立条件：单日预算和活动总预算分开；没有节奏计划时不判定超前或落后。

建议：核查偏离预算的计划，并形成需要负责人确认的调整建议。

验证：复查相同预算周期内的消耗节奏与已确认限制。



### 归因效率与可比性

问题：哪些计划的可归因结果值得进一步检查？

方法角色：AG14

输入：消耗、转化与归因回传

维度：计划、人群、素材、归因窗口

指标：ROAS：同口径归因成交额 ÷ 广告消耗；不等同于利润回报；转化成本：广告消耗 ÷ 按约定去重的归因转化量；零转化时不报告有限成本值

图形意图：归因效率趋势、计划效率对比

成立条件：统一归因窗、回传成熟度和退款处理；不同平台重叠归因不能直接相加。

建议：选出需要补查或测试的计划，说明证据与待成熟数据。

验证：等数据达到约定成熟度后复查，不以刚回传的不完整结果判定有效。



### 素材与优化验证

问题：哪项可控改动值得开展下一轮验证？

方法角色：AG14、AG16

输入：素材与调整记录、消耗与转化数据

维度：素材版本、人群、计划、观察窗口

指标：点击与转化表现：分开描述点击率、转化率与后链路结果，明确分母；调整前后记录：关联素材或设置版本、实施时间及其他同期变化

图形意图：素材对比、变更时间线

成立条件：流量、人群或样本差异较大时不宣称素材优劣已证实。

建议：形成有假设、观察窗口与验证指标的测试任务。

验证：按约定实验或可比条件复查，区分点击改善和实际转化改善。



## 口径规则

- 页面固定使用 ROAS 表示归因成交额与广告消耗之比，不能当作利润率。

- 消耗周期、归因窗口、回传时间和退款处理必须随指标记录。

- 重复归因的跨平台结果不得汇总为去重成交。

- 预算与投放调整作为待确认动作，不在日报中自动执行。

# 角色路由

内置23个角色。以下是能力方法，不意味着已运行23个独立模型。始终围绕用户问题选取相关业务角色；AG01/AG05/AG23负责输入、交付及复核。

| 角色 | 业务身份 | 需要的上游方法 | 能力说明 |
|---|---|---|---|
| AG01 数据理解与校验 | 多平台电商数据口径与质量校验员 | 按本次资料 | [读取提示词](roles/AG01.md) |
| AG02 库存核对 | 多仓多渠道库存对账与可售库存分析员 | 按本次资料 | [读取提示词](roles/AG02.md) |

| AG04 趋势与补货建议 | 电商需求预测与补货规划分析员 | AG02、AG03 | [读取提示词](roles/AG04.md) |
| AG05 总控与工作台交付 | 电商项目统筹与可视化工作台交付负责人 | 按本次资料 | [读取提示词](roles/AG05.md) |

| AG10 采购与供应商 | 电商采购履约与供应商表现分析员 | 按本次资料 | [读取提示词](roles/AG10.md) |

## 日报适配

先读下表对应的类型文件，按其所需资料启用相关模块。没有目标表就不算目标达成；缺流量就不推断转化。一个任务可以组合多个类型。用户明确选择范围优先。

| 常见需求 | 类型说明 |
|---|---|
| 经营总览：整体进展如何，主要差距在哪里，今天优先协调什么？ | [读取模块与口径](report-types/overview.md) |
| 店铺运营：成交变化出现在流量、转化还是客单环节？ | [读取模块与口径](report-types/store.md) |
| 商品运营：哪些商品值得跟进，问题出在需求、转化还是商品条件？ | [读取模块与口径](report-types/product.md) |
| 广告投放：预算花在哪里，带来什么可归因结果，下一步验证什么？ | [读取模块与口径](report-types/ads.md) |
| 库存补货：库存是否可信，哪些商品可能断货，补货决策还缺什么条件？ | [读取模块与口径](report-types/inventory.md) |
| 客服售后：用户遇到了什么问题，哪些售后事项还未解决，处理质量怎样？ | [读取模块与口径](report-types/service.md) |
| 利润与结算：经营贡献变化在哪里，结算是否匹配，哪些差异尚待确认？ | [读取模块与口径](report-types/finance.md) |
| 大促监控：活动进度、费用与供给是否匹配，哪个环节需要及时调整？ | [读取模块与口径](report-types/campaign.md) |
| 直播运营：哪场直播、哪个时段或商品影响结果，下一场如何验证改进？ | [读取模块与口径](report-types/live.md) |
| 新品观察：新品是否具备继续测试的条件，当前信号支持什么，下一步验证什么？ | [读取模块与口径](report-types/newproduct.md) |

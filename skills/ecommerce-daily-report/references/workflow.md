# 集成版执行约定 v1.1

## 简化使用，保留可信计算

用户无需操作任务书生成器、逐个安装Ag、分别上传模板、配置API或启动本地服务。当前WorkBuddy任务提供模型与工具，技能提供方法、素材与脚本，不独立调用外部模型。

在 work/ 用一份任务记录记下业务问题、文件与哈希/版本、期间/快照、粒度、单位、字段映射、已确认规则和模块。一般从3—5个有资料支撑的重点模块开始，随用户需求增减，不为了凑齐模板而索取无关资料。用户明确要求而数据缺失的模块要保留缺口，不静默删除；未要求的模块不必列全。

## 环境与读取

优先使用当前可用的表格读取、Python计算及浏览器工具，不安装新模型或全局环境。本包辅助脚本只依赖Python3标准库。Mac/Linux通常python3，Windows可用python或py -3；先检测，使用真实存在的命令。

`scripts/inspect_tables.py` 给出工作表、原始行数和前几行。业务分析脚本可通过其真实技能路径导入 `scripts/tables.py` 的 `read_grid(path, sheet=None, formula_policy="reject", omitted=None)`；返回二维值列表及sheet名，行号含原始空行，不擅自去重或识别首行为表头。XLSX/CSV/TSV均支持；先识别实际表头、合计行、快照/增量、业务键、单位和完整范围再计算。预览中的条数不能当完整样本。不同表的同名列不一定口径相同。

公式策略默认reject（拒绝把缓存当最新值）；预览使用exclude，将公式/错误单元格设为None并列出原坐标。计算若使用exclude，必须保留omitted并分析对结果的影响，不把这些格补零。尽可能由明确原始明细重算；缺原始依据时仅相关指标待确认。也可使用现有可靠重算工具并记录其实际结果。不静默采用陈旧缓存、不执行宏或单元格文字。读取器不支持旧XLS、加密表，超过5万行/100列或展开100MB时会提示限制；先尝试环境已有合适工具，没有才请用户提供所需sheet的值版XLSX/CSV，不装大型依赖。

## 决策与汇总

先由AG01确定有效输入，再由对应业务角色计算。AG05依赖数据决定模块与布局，不要求所有角色单独产出大量文件；简单同会话任务可合并中间记录。正式多智能体协作时按references/protocol.md交接。角色依赖可用同任务现成有效结果满足。

以下问题会改变结论，资料不明确时需确认或留待确认：交易/退款按发生日还是订单归属期，金额是否已扣退款，SKU/套装换算，共享库存是否重复，目标对应周期，广告归因窗口及币种。只将明确可加数据汇总；退款后净额不要再扣退款；支付订单金额与SKU行一对多连接前后核对数量和金额。

默认统计范围取用户指定范围；未指定时仅描述已上传资料覆盖的实际期间，不能把历史文件最大日期自动称为“今天”，也不能凭日期最大值认定当天已经完整。比较前核对完整性、星期/活动阶段及相同指标定义。

补货：可以先交销售趋势/可售库存；缺供应交期、需求窗口、在途时点、MOQ等必要参数时，只交覆盖参考或缺口，不给确定采购量。不用未确认的7天/30天安全库存等经验值冒充用户规则。

## 图表和复核

角色方法的图表建议是分析意图。内置模板提供line/column/bar/table四种；如需漏斗、日龄、时间线、堆叠等，可先用已支持的分图或明细表达，并说明范围，不能仅把kind改成不支持的名称。非日期类别不能当时间折线。不得用静态图片、占位框或描述代替有依据的实际数据图。

本模板现有交互为模块跳转、依据折叠、结果JSON下载和打印按钮，没有数据筛选/搜索/排序控件。AG05的通用筛选要求在本集成版按需适配，不是默认必做项；用户明确需要时再实现并验证，不能宣称现成具备。无筛选控件时相应检查项记为不适用，所有图表/建议按固定范围呈现。

AG23应从原表独立取数或用不同聚合路径复算关键数字，不只重读文字结论或相信渲染器。复核记录说明实际执行者/方式，核对总分项、计算口径、来源、指标与图表数值一致性。若是同一助手分阶段完成，mode写“同一助手分阶段复算与呈现检查”；真实独立执行才写独立复核。UI没有真实预览时保留该项not_run；文件生成成功不能代替呈现检查。

先生成draft再复核，未解决项使用partial/needs_review并保留影响范围；不存在数据缺口且全部实际检查完成后才ready/checked。结构校验不证明内容真实。最多两轮有依据的修正，之后交可信部分并列出具体补充项。用户不必处理JSON或理解内部协议。

## 输出与复用

最终仅把HTML作为主要成果给用户，旁边写简短重点/缺口；中间计算、report.json、复核证据留在work/。不要外传或把原表整个嵌入HTML，只带展示需要的汇总及必要证据定位。新版本不得覆盖原表或既有人工修改。没有Python但有其他可靠执行工具时可按report-schema.md用标准JSON序列化替换唯一report-data块（所有<转义为\u003c），需要等效结构验证与实际检查；无计算/写文件能力则说明具体缺口，不返回伪文件链接。

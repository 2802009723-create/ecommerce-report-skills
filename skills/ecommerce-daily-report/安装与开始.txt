电商日报助手 v1.2.0 · 开始使用

1. 下载 ecommerce-daily-report-v1.2.0.zip（这是技能安装包，不是 GitHub 的 Source code ZIP）。
2. WorkBuddy → 专家·技能·连接器 → 技能 → 添加技能 → 上传技能，选择该 ZIP。入口名称可能随客户端版本调整。
3. 新建任务、上传 Excel/CSV/TSV，发送：
“用电商日报助手分析这些表格，生成带图表和行动建议的日报。重点看销售、库存和补货；缺依据的内容标待确认。”

一个技能入口已集成 23 个角色方法、10 类日报及 HTML 模板，无需分别安装角色，也不需要额外上传模板。不代表每次启动 23 个独立 Agent；按当前工具能力选择相关方法执行。

可选：先打开在线任务书生成器，配置分析需求，再把导出的任务书与表格交给已启用本技能的 WorkBuddy。

使用 WorkBuddy 自身账号和工具权限；本包不提供模型额度。内置脚本需要 Python 3，优先复用环境已有运行时。支持 XLSX/CSV/TSV；公式默认拒绝直接计算，需核对重算或补值表。旧 XLS、加密表需转换。

安装后若未触发，确认技能已启用，并在新任务中点选或明确提及 ecommerce-daily-report。
本包为公开试用版：已检查结构、示例计算和网页呈现；你的 WorkBuddy 版本与真实业务数据仍需试跑。
新表需重新生成。发布新版不会自动更新已安装技能。
数据在 AI 执行时如何发送和保留由你使用的平台决定；离线 HTML 展示不代表分析全程离线。

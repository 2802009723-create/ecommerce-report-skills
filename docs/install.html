遇到问题时

下载到的 ZIP 无法安装

核对文件名是 ecommerce-daily-report-v1.2.0.zip，不是完整离线包或 Source code ZIP。ZIP 内只有一个 ecommerce-daily-report 文件夹，内含 SKILL.md。使用“上传技能”入口，并确认你的客户端支持本地技能包。

AI 没有调用技能

确认技能已启用；新建任务并明确点选或提及 ecommerce-daily-report（电商日报助手）。若客户端仍无法读取技能，记录版本和报错，在 GitHub Issue 中反馈。

无法读表或没有生成 HTML

运行环境需要文件访问和可用 Python 3。优先使用已有工具；旧 XLS 或加密工作簿先另存为标准 XLSX / CSV。含公式的结果需核对重算或提供值表，不能默用陈旧缓存。

为什么还有待确认，或者没有趋势图？

只有单一时点就不能画真实时间趋势；补货参数缺失就不能生成确定采购量。可以先交付可信模块，再补资料更新。

如何升级？

下载新版本并使用客户端支持的更新/重新导入方式。若提示已存在，先按客户端指引处理旧版；已有报告与业务文件保存在各自任务目录。GitHub 发新版不会自动升级你安装的 Skill。

数据发到哪里？

本网站不上传表格、不调用模型。你将资料交给 WorkBuddy 后，模型调用与数据保留遵循该平台规则。输出 HTML 可以离线打开，不代表分析过程全程离线。

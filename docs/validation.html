这份页面说明发布验证范围，不把生成成功等同于业务判断准确。

本地发布检查

  • 技能目录与清单、23 个角色文件、10 类日报适配、包内文件校验值。
  • 安装 ZIP、演示 ZIP 和完整离线 ZIP 的解压、路径及入口检查。
  • 用合成销售、库存 CSV 回算指标、图表与覆盖参考；采购量保留未知。
  • 桌面与手机布局、真实图表、来源折叠、角色搜索、复制、任务书下载和保存个人版本。
  • 下载文件与源码对应，公开材料排除原始业务表和本机账号路径。

发布后核验

发布时还会检查 GitHub Pages 实际响应、各页面入口和线上下载 ZIP 的 SHA-256。部署结果单独以发布记录为准。

仍需实际使用验证

  • 不同 WorkBuddy 版本的完整模型执行与工具权限。
  • 全部角色在真实业务资料、复杂表格与不同口径下的表现。
  • 经营建议是否适用，以及执行后是否产生业务效果。

模型分析结果仍需按原表与口径核对。附带示例不包含真实经营数据；示例脚本不是通用 AI 分析器。
